# CRUX.

A calm, personal bouldering log for iPhone. Log climbs, attempts and sends in a tap, let sessions track themselves, keep a tick list, and follow your progress — all on-device.

Built around the **Hex grading** used at Hive Climbing (Metro Vancouver).

> 🚧 In active development.

## Tech
SwiftUI · SwiftData · Swift Charts · Core Haptics · iOS 26 · no third-party dependencies.
